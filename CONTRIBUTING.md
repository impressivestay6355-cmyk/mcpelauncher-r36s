# Contributing

Bug reports and compatibility reports are the most useful contribution
right now — this port is early and not every APK version has been tested.

## Reporting an issue

Please include:

- Device and OS build (e.g. R36S / DarkOS, R36S / ArkOS4Clones)
- Minecraft Bedrock APK version tested
- What you expected vs. what happened
- Relevant lines from the launcher log, if available

## Do not attach

- Minecraft APKs or extracted game files
- Any other Mojang/Microsoft copyrighted asset

Reports that depend on those files to reproduce can't be handled publicly.

## Pull requests

Small, focused changes are easiest to review — script fixes, compatibility
patches, documentation. For anything larger, open an issue first to
discuss the approach.
